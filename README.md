# Fast Internet Downloader

**Files, videos, and audio - managed in one native Windows app.**

Fast Internet Downloader (FID) helps you download files with multiple connections, pause and resume transfers, organize your queue, and send downloads straight from your browser. Available for Windows 10 and Windows 11.

## Features

- **Multi-connection downloads** - use up to 16 connections per file, with automatic single-connection fallback when needed.
- **Pause and resume** - keep partial downloads and validate the source before continuing.
- **Queues and history** - run up to 16 downloads at once, reorder priorities, and keep your download list between sessions.
- **Scheduling and speed limits** - delay a download's start and control its bandwidth usage.
- **Retries and recovery** - retry temporary failures and optionally resume interrupted downloads after an app restart or internet outage.
- **Browser integration** - send links through a right-click menu, optionally capture browser downloads, and exclude individual websites.
- **Video and audio downloads** - choose available qualities, download audio only, and merge separate video and audio streams using yt-dlp and FFmpeg.
- **In-page video controls** - choose downloads from supported players, with direct media and HLS/DASH detection where available.
- **Expired-link refresh** - obtain a fresh link through your browser and reuse partial data when the source can be verified.
- **Detailed progress** - track speed, remaining time, and individual file connections in separate progress windows.
- **Flexible file management** - choose download and temporary folders, edit filenames, and avoid overwriting existing files.
- **Windows integration** - follow taskbar progress, keep downloads running in the notification area, and optionally launch with Windows.
- **Encrypted browser pairing** - approve each browser profile once; browser-to-app messages use an encrypted local connection.

Download speed and resume support depend on the source server. Video features depend on website support and installed media tools; DRM-protected media is unsupported.

## Browser extensions

Install the Windows app first, then add the extension for your browser:

| Browser | Extension |
| --- | --- |
| Google Chrome | [Install from Chrome Web Store](https://chromewebstore.google.com/detail/fast-internet-downloader/mglbbomaapnefdmeolidpkgafhlenkod) |
| Microsoft Edge | [Install from Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/fast-internet-downloader-/achgodglkmdoemhgfankhbmibgccdomf) |
| Mozilla Firefox | [Install from Firefox Browser Add-ons](https://addons.mozilla.org/en-US/firefox/addon/fast-internet-downloader/) |
| Brave | [Install the Chrome Web Store extension](https://chromewebstore.google.com/detail/fast-internet-downloader/mglbbomaapnefdmeolidpkgafhlenkod) |
| Opera | [Install the Chrome Web Store extension](https://chromewebstore.google.com/detail/fast-internet-downloader/mglbbomaapnefdmeolidpkgafhlenkod) |

Open the extension, choose **Connect / open FID**, then **Open FID and connect**. Allow the browser to open FID and approve the connection in the desktop app. The extension displays **Desktop connected** when ready. Automatic download capture is optional and starts disabled.

See the [official browser extension guide](https://fastinternetdownloader.com/docs/browser-extensions/) for browser-specific setup and source ZIP downloads. Available browser features depend on the installed extension and desktop release.

## Get started

1. [Download and install FID](https://fastinternetdownloader.com/download/) for Windows 10 or Windows 11 (64-bit).
2. Open FID and choose **Add URL**, or send a link through a connected browser extension.
3. Choose the filename and destination folder. For videos, select an available format or quality.
4. Confirm the download, or choose **Download later** to keep it paused in the queue.

The desktop app also works without a browser extension. For more help, read the [online documentation](https://fastinternetdownloader.com/docs/).
